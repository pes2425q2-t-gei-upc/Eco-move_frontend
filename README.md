# eco_move_frontend

##ECO-MOVE
ECO-MOVE es una aplicación móvil pensada para facilitar la movilidad urbana sostenible. Permite encontrar estaciones de carga para vehículos eléctricos, reservar bicicletas, localizar refugios climáticos y gestionar alertas de emergencia. Además, incorpora funciones avanzadas como filtrado por tipo de vehículo, integración con calendarios y un sistema de gamificación.

##Funcionalidades principales

##Estaciones de carga para vehículos eléctricos
- Muestra estaciones de carga en un mapa.
- Permite realizar reservas de estaciones que incluyen valoraciones y reseñas de otros usuarios.
- El usuario puede guardar la información de su vehículo para filtrar estaciones compatibles.

##Reserva de bicicletas
- Muestra bicicletas disponibles en el mapa.
- Permite reservar bicicletas directamente desde la app.

##Refugios climáticos
- Muestra la ubicación de refugios climáticos en el mapa.

##Alertas de emergencia
- Si un usuario se queda sin batería, puede enviar una alerta de emergencia con su ubicación.
- Los demás usuarios reciben una notificación con las coordenadas.
- Al aceptar una alerta, se inicia un chat con el usuario que la ha enviado para coordinar el encuentro.

##Gestión de reservas
- Las reservas se guardan en un calendario interno de la aplicación.
- También se pueden sincronizar con Google Calendar de forma opcional.

##Sistema de gamificación
- Por cada reserva realizada, el usuario gana 10 puntos.
- Existen distintos niveles y trofeos que se desbloquean al acumular puntos.
